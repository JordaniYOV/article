# Evaluating Vision Models on Planetary Surfaces

Рабочее название статьи охватывает VLM и визуальные энкодеры. Текущая область
исследования — орбитальные снимки поверхности Луны и Марса.

Здесь будут текст, проверенные таблицы и ссылки на версионированные результаты.
Рабочий замысел хранится в [`research_plan.md`](../research_plan.md). Основной
планируемый опыт сравнивает замороженные визуальные признаки с головами одного
типа; сравнение полных систем остаётся отдельным анализом.
Не заполнять таблицы предполагаемыми числами до реальных экспериментов.
